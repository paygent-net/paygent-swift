# Licence FAQ

This repository is licensed under the Business Source License 1.1 (BUSL-1.1).
The full text, including our Additional Use Grant, is in [LICENSE](LICENSE).
This page explains it in plain language. If the two disagree, the licence
wins.

**The short version:** you can read it, run it, and ship it unmodified, for
free, commercially or not. You can change it for your own personal use, or to
contribute the change back. Changing it for a business, or shipping a changed
version, needs a commercial licence. Four years after each release, that
release becomes Apache-2.0.

## Can I use it in my company?

Yes. Production use of the unmodified code is free for any purpose, at any
scale. Configuring it, including choosing your own relay, RPC endpoint, bundler
or fee payer, is not a modification.

## Can I run it against my own infrastructure?

Yes. As a user you may point it at any relay, RPC endpoint, bundler or fee
payer you like. The licence never restricts an end user's choice of
infrastructure.

## Can I fork it and change it?

For personal, non-commercial use: yes. Reading, forking, modifying and
redistributing source for non-production purposes is always allowed, so
forking on GitHub and experimenting is fine.

Running a modified version in production for a business, or on behalf of one,
needs a commercial licence. The exception is a change you contribute back: a
modification submitted to us for inclusion is permitted for any purpose.

## Can I ship it inside my product?

Yes, unmodified, and with Paygent's default infrastructure as the defaults
your product ships with. Your users can still reconfigure it. Shipping a
modified version, or shipping with other infrastructure as the default, needs
a commercial licence.

## I found a bug. Can I patch it?

For personal use, yes. For commercial use, contribute the fix as a pull
request (which makes it permitted for any purpose) or wait for a release. If
that is not workable for you, contact us about a commercial licence.

## When does it become open source?

Each version converts to the Apache License 2.0 four years after it is first
published. The date is per version, so older releases open up first.

## Why not a standard open-source licence?

Paygent is self-custody wallet software that signs payments. We want anyone to
be able to read it, audit it, run it and build on it, and we want every user to
keep the right to operate without us. We also need to keep the product coherent
while it is young: one implementation whose behaviour with money we can vouch
for. BUSL gives both, with a fixed date on which each version opens fully.

Email support@paygent.net.

## Does this cover the name and logo?

No. The licence grants no trademark rights. See
[paygent.net/trademark](https://paygent.net/trademark) for what you may do
without asking.
